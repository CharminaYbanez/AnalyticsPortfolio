The project has been scoped as a two-day healthcare operations mini project focused on emergency-department throughput benchmarking using CMS hospital public reporting data.

## Project Title

Healthcare Operations Analytics — ED Throughput Benchmarking

## Project Type

Mini portfolio project

Planned duration:

- Day 1: SQL staging and QA
- Day 2: Python analysis, visuals, findings, and portfolio packaging

## Business Context

Emergency departments are high-pressure operational environments where throughput delays can affect patient experience, care access, staffing burden, and hospital operations.

This project uses CMS hospital-level public reporting data to screen for hospitals with elevated emergency-department throughput indicators relative to available ED-volume peer categories.

The analysis is designed to support operational review prioritization, not to diagnose the causes of performance differences.
